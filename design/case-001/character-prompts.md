# Character Prompts: one per person (for ChatGPT)

**Why the faces came out the same:** when you upload Shivvya as a reference, ChatGPT copies **her face, pose, jacket, lamp and desk**, not just the art style.

## Rules (follow every time)

1. **Open a NEW chat for every character.** An old chat remembers the last face.
2. **Don't upload any image.** Every prompt below already describes the art style in words.
3. **Paste the whole block** for one character, exactly as written.
4. If the result still looks like someone else, reply:
   > *"The face is too similar to my other character. Make the face shape, nose, eyes, eyebrows and hair clearly different, keep everything else."*
5. If the **style** drifts (too realistic, too cute), only then upload `story/government official.png` (the director) and say *"Match only the drawing style of this image. Do NOT copy the person, pose or room."*
6. Ask for a **landscape 3:2 image** (the prompt already says so).

Each character has a **different pose, light colour and setting**, so they never look like copies:
